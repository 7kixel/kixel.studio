KIXEL STUDIO — SITIO WEB

Archivo principal: index.html

Estructura:
- assets/css/style.css: estilos, responsive y animaciones.
- assets/js/app.js: contenido y aplicación React.
- assets/vendor/: React y ReactDOM.
- assets/images/banner.png: banner principal.
- assets/images/foto-perfil.jpg: foto de perfil.

El logo.png fue eliminado y se reemplazó por un identificador tipográfico simple en la navegación.

Para visualizarlo, abrir index.html o ejecutar un servidor local en esta carpeta:
python -m http.server 8000
Luego entrar a http://localhost:8000
